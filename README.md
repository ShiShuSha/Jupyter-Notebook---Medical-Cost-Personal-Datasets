# Итоговый проект: анализ датасета Medical Cost Personal Datasets

Автор: Мальгин Олег, 3 курс

Курс: Python для анализа данных

Учебный проект по анализу данных о медицинских расходах застрахованных лиц. В ноутбуке выполнен полный цикл анализа: загрузка и описание данных, очистка, исследовательский анализ, статистическая проверка гипотезы, визуализация, корреляционный анализ и линейная регрессия.

## Данные

- Датасет: Medical Cost Personal Datasets
- Источник: https://www.kaggle.com/datasets/mirichoi0218/insurance/data
- Файл: `insurance.csv`
- Объём: 1338 наблюдений, 7 признаков
- Целевая переменная: `charges` (годовые медицинские расходы)

## Файлы проекта

- `Мальгин_итоговый_проект.ipynb` - ноутбук с анализом, графиками и выводами (все ячейки выполнены)
- `insurance.csv` - исходные данные
- `README.md` - описание проекта

## Содержание ноутбука

1. Датасет и описание данных
2. Фильтрация, сортировка и создание новых признаков
3. Частотные и сводные таблицы
4. Пропуски и выбросы
5. Описательная статистика
6. Сравнение групп и проверка статистической гипотезы
7. Визуализация данных
8. Корреляционный анализ
9. Линейная регрессия
10. Итоговые выводы

## Основные результаты

- Курение - главный фактор расходов: у курильщиков они в 3.8 раза выше, различие статистически значимо (критерий Манна-Уитни, p < 0.001)
- Возраст - второй по значимости фактор: средние расходы растут с 9.2 до 21.2 тыс. долл. от группы 18-29 лет к группе 60+
- Модель линейной регрессии: R2 = 0.745 на тестовой выборке, MAE = 4126 долл.
